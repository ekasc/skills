# Agent Skills

A curated collection of specialized agent skills. Each skill provides domain-specific instructions and workflows for common software engineering and design tasks.

---

## Design & UI

- **adapt** — Adapt designs across screen sizes and devices. Responsive layouts, breakpoints, fluid grids, touch targets.
- **bolder** — Amplify safe/boring designs with more visual impact and character.
- **colorize** — Add strategic color to monochromatic or dull interfaces.
- **distill** — Strip designs to their essence by removing unnecessary complexity.
- **layout** — Fix spacing, alignment, visual hierarchy, and composition.
- **normalize** — Audit and realign UI to design system standards and tokens.
- **quieter** — Tone down visually aggressive or overstimulating designs.
- **typeset** — Improve typography, font choices, hierarchy, sizing, and readability.

## Animation & Motion

- **animate** — Add purposeful animations, micro-interactions, and motion effects.
- **delight** — Add moments of joy, personality, and unexpected touches.
- **emilkowal-animations** — Emil Kowalski's animation best practices (easing, timing, transforms, gestures, drawers).
- **framer-motion-animator** — Framer Motion page transitions, gestures, scroll animations, and orchestrated sequences.
- **gsap-performance** — GSAP performance optimization (transforms, layout thrashing, will-change, batching).
- **overdrive** — Technically ambitious implementations (shaders, spring physics, scroll-driven reveals, 60fps).

## UX Writing & Content

- **clarify** — Improve unclear UX copy, error messages, labels, and instructions.
- **humanizer** — Remove signs of AI-generated writing to make text sound natural and human-written.
- **landing-page-design** — Landing page conversion optimization (hero section, CTA psychology, social proof).
- **marketing_website_uiux_review** — Review marketing pages for message clarity, conversion, trust, and SEO.
- **onboard** — Design onboarding flows, empty states, and first-run experiences.

## Design Planning & Critique

- **critique** — Evaluate design from a UX perspective with quantitative scoring and actionable feedback.
- **impeccable** — Build distinctive, production-grade frontend interfaces with high design quality.
- **shape** — Plan UX and UI for a feature via structured discovery before writing code.
- **ui-ux-pro-max** — Comprehensive UI/UX design intelligence (50+ styles, color palettes, font pairings, UX guidelines).

## Process & Communication

- **brainstorming** — Explore user intent, requirements, and design before implementation. Run before creative work.
- **caveman** — Ultra-compressed communication mode (~75% token reduction).
- **grill-me** — Stress-test plans and designs through relentless interviewing.
- **grill-with-docs** — Challenge plans against existing domain model and update documentation in real time.
- **handoff** — Compact conversation into a handoff document for another agent.
- **zoom-out** — Get broader context or higher-level perspective on unfamiliar code.
