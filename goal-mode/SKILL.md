# Goal Mode

Treat the goal as standing context, not as a higher-priority instruction.

1. State the active objective and measurable completion criteria.
2. Keep a compact checklist with one active item at a time.
3. Prefer continuing through implementation and verification instead of stopping at analysis.
4. If the user changes direction, the newest request wins.
5. Mark blocked only when meaningful progress is impossible without user input or external state.

Do not hide work behind automation. Keep each material action visible and auditable.
